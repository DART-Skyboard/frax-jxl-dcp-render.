Frax JXL DCP Render

A Blender extension that renders JPEG XL stills and animations and builds festival DCPs. Requires Blender 5.2 LTS or later.

Quick start

  1. Install the extension (Preferences → Get Extensions, or Install from Disk with a zip from Releases).
  2. Open Output properties → JPEG XL (Frax).
  3. Set the frame range and an output path that exists, for example /home/you/renders/shot.jxl. Save the .blend first if you use a // relative path.
  4. Press Render Animation → JPEG XL and let every frame finish. The animated .jxl is written for you.

Troubleshooting

"This platform isn't one of (windows-x64, …)" on Android

The store package lists desktop platforms only. Use the Android build from Releases (the -android zip) and pick the pure-Python encoder.

enum "TIFF" or "PNG" not found in ('FFMPEG')

Fixed in 1.2.2. Blender 5 separates Media Type from File Format; older versions tried to set TIFF while Media Type was Video. Update, then restart Blender completely, because reinstalling does not reload add-on code that is already running.

The saved .jxl is tiny / one frame

Image → Save As in the Render Result window saves only the frame on screen. Use Render Animation → JPEG XL.

The output path box is red

The path cannot be resolved. Save the .blend (for // paths) or choose a full path to a folder that exists.

Can't open a long .jxl on my device

Browsers and some viewers load every frame. Use a player that decodes frame by frame,.
